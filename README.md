# StudyHub — Học lập trình mỗi ngày

Chào mừng bạn đến với StudyHub! Đây là website giúp học sinh học lập trình từ cơ bản đến nâng cao.

## Các khóa học
- **HTML & CSS:** Học tạo và thiết kế trang web.
- **JavaScript:** Học lập trình và tạo tính năng tương tác.
- **Python:** Làm quen với ngôn ngữ lập trình Python.

## Tính năng
- Giao diện hiện đại, dễ sử dụng.
- Các khóa học lập trình dành cho người mới bắt đầu.
- Thử thách thực hành và kiểm tra đáp án.
- Theo dõi tiến độ học tập.

## Công nghệ
- HTML
- CSS
- JavaScript

## Mục tiêu
Giúp học sinh học lập trình dễ dàng, rèn luyện tư duy logic và tự xây dựng các sản phẩm công nghệ của riêng mình.
